🐍 Довідник команд Python (Scratch & VEX)

Повний перелік команд для керування роботом RoboCodo у Python.

🚶 Scratch Рух (Motion)

robot.move_steps(10)

Перемістити робота вперед на зазначену кількість кроків у напрямку погляду (1 крок = 10 мм).

robot.turn_angle('RIGHT', 15) / robot.turn_right(15)

Повернути праворуч (за годинниковою стрілкою ↻) на зазначену кількість градусів.

robot.turn_angle('LEFT', 15) / robot.turn_left(15)

Повернути ліворуч (проти годинникової стрілки ↺) на зазначену кількість градусів.

robot.turn_to_heading(90) / robot.point_in_direction(90)

Повернути в абсолютний напрямок: 0° = вгору (північ), 90° = праворуч (схід), 180° = вниз (південь), -90° (270°) = ліворуч (захід).

robot.point_towards('obstacle')

Повернути робота прямо на перешкоду або в напрямку цілі.

robot.goto_xz(x, z)

Миттєво перемістити робота в задані координати.

robot.glide_to_xz(secs, x, z)

Плавно ковзати протягом зазначеного часу до координат X та Z.

robot.change_x(10) / robot.set_x(0)

Змінити або встановити координату X.

robot.change_z(10) / robot.set_z(0)

Змінити або встановити координату Z (вперед/назад).

robot.bounce_on_edge()

Якщо робот торкається межі карти — автоматично відбитися і розвернутися зі звуком.

💬 Scratch Вигляд (Looks)

robot.say("Привіт!", 2)

Показати 3D хмаринку репліки над роботом на задану кількість секунд.

robot.set_size(150) / robot.change_size(10)

Встановити або змінити масштаб 3D моделі робота у відсотках.

robot.show() / robot.hide()

Показати або сховати робота на 3D сцені.

🔊 Scratch Звуки (Sound)

robot.play_sound('beep'), 'pop', 'jump', 'laser', 'coin'

Відтворити звуковий ефект через синтезатор Web Audio API.

🖍️ Перо (Pen)

robot.set_pen('DOWN') / robot.set_pen_down(True)

Опустити перо для малювання сліду на полі.

robot.set_pen_color('GREEN') або robot.set_pen_color('#4C97FF')

Встановити колір пера.

robot.set_pen_width(8)

Встановити товщину лінії.

👀 Датчики та Сенсори

robot.is_touching('obstacle') / 'edge'

Повертає True, якщо робот торкається перешкоди або межі майданчика.

robot.get_distance('FRONT', 'MM')

Виміряти дистанцію до найближчого об'єкта лазерним далекоміром.

robot.get_angle()

Отримати поточний кут повороту робота.

robot.get_loc('X', 'MM') / robot.get_loc('Z', 'MM')

Отримати позицію робота у міліметрах.

robot.jump()

Підстрибнути вгору.

robot.reset()

Скинути позицію на стартову.
